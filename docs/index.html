Qiita Trend Cleaner

Qiita のトレンドを自分の基準で整理する Chrome 拡張機能です。短時間に同じメンバーからのいいねが集中している記事を検出して隠せるほか、トークンを設定すると記事の文体から「AI文体かも？」という目安を表示します。

Qiita 株式会社とは無関係の非公式な拡張機能です。個人が開発・公開しています。

仕組み

同じアカウントの集まりが複数の記事へ短時間にいいねしている共起パターンを、ブラウザに貯まったデータから見つけます。検出された著者はポップアップに一覧表示され、「妥当 / 誤り」はあなた自身が判断します。

判定の条件はスライダーで自由に変更できます。「妥当」と評価した著者はトレンド上から隠せるほか、設定をオンにすれば Qiita 側のミュートも同時に行えます（初期設定はオフ）。一括での自動ミュートやブロックは行いません。

不正とは決めつけません

この拡張機能が出すのは「いいねの重なり方」と「文体の目安」だけで、不正や規約違反を判定するものではありません。同じ組織やコミュニティの人たちが互いの記事を読んでいいねした場合も、同じパターンとして現れます。

誤検知は起こります。根拠の記事を確認したうえで、あなた自身が判断してください。

データの扱い

データの保存先はあなたのブラウザ内（chrome.storage）だけで、外部サーバーへの送信はありません。通信先は Qiita の公式 API のみです（ミュート操作のリクエストは Qiita のページ自身が発行します）。

収集したいいねの記録は 7 日で自動的に削除されます。また、「AI文体かも？」のために取得した記事の本文はブラウザ内で数えた直後に破棄し、保存しません。要求する権限は storage と https://qiita.com/* だけです。

詳しくはプライバシーポリシーをご覧ください。
