Qiita Trend Cleaner

Qiita のトレンドから不自然ないいねパターンが見られる記事を検出して隠す Chrome 拡張機能です。

Qiita 株式会社とは無関係の非公式な拡張機能です。個人が開発・公開しています。

これは何をするか

同じアカウントの集まりが複数の記事に短時間でいいねを集中させている——この共起のパターンをローカルに蓄積したデータから検出します。検出した著者は一覧に出ます。「妥当 / 誤り」はあなたが判断します。

  • 判定はあなたが決めた閾値で行われます
  • 「妥当」と評価した著者を Qiita 側でミュートすることもできます（既定はオフ）
  • 一括自動ミュートはしません。ブロックも行いません

断定はしません

この拡張が示すのは「不自然ないいねパターン」だけです。不正や規約違反とは断定しません。同じ組織の人が互いの記事を読んでいいねするのは正常な行動です。それも同じパターンとして現れます。

誤検知は起こります。判断は必ずあなたが行ってください。

データの扱い

  • 保存先はあなたのブラウザの中だけです。外部サーバーへの送信はありません
  • 通信先は Qiita の公式 API のみ
  • 収集した いいね の記録は7 日で自動的に破棄されます
  • 権限は storage と https://qiita.com/* だけです

詳しくはプライバシーポリシーをご覧ください。
