Chrome 拡張機能 Qiita Trend Cleaner（以下「本拡張」）／ 最終更新 2026-09-05

本拡張は Qiita 株式会社とは無関係の非公式な拡張機能です。個人が開発・公開しています。

収集したデータを外部のサーバーへ送信することはありません。通信先は Qiita の公式 API のみで、開発者が運営するサーバーは存在しません。解析ツール・広告・トラッカーの たぐいは一切組み込んでいません。

1. 保存する情報

本拡張が保存する情報は次のとおりです。いずれもお使いのブラウザの中にのみ保存されます。

情報 保存先 用途と保持期間
Qiita アクセストークン chrome.storage.local 任意設定です（未設定でも動作します）。Qiita 公式 API の認証にのみ使用します。他のいかなる送信先にも送りません。 設定画面からいつでも削除できます。
いいねの記録 chrome.storage.local 「どの Qiita アカウントが、どの記事に、いつ いいね したか」。共起パターンの判定に 使用します。7 日を過ぎたものは自動的に削除されます。
検出結果とあなたの評価 chrome.storage.local 検出した候補と、それに対してあなたが記録した「妥当 / 誤り」の判断。
ミュートの記録 chrome.storage.local 本拡張から Qiita 側のミュートを実行した結果。
判定の設定値 chrome.storage.sync 閾値の数値のみ（人数・記事数・遡る日数・時間の幅）。 Chrome の同期機能の対象なので、同期を有効にしている場合は Google の サーバーを経由してお使いの他の端末にも反映されます。 個人を識別する情報は含みません。

2. 他の利用者のアカウント情報について

本拡張は、あなたが表示しているトレンドページの記事に「いいね」した Qiita アカウントの ID を、 共起パターンの判定のために記録します。これは第三者の情報にあたるため、次の扱いとしています。

  • 外部へ送信しません。あなたのブラウザの中だけで処理します
  • 7 日を過ぎたものは自動的に削除されます（保持期間を延ばす設定はありません）
  • 他の利用者と共有・配布する機能はありません
  • 本拡張は「不自然ないいねパターン」を示すだけで、不正や規約違反を断定しません。 判断は利用者自身が行います

3. 通信先

本拡張が通信するのは https://qiita.com/api/v2（Qiita 公式 API） のみです。

トレンドページの記事一覧は、あなたが表示しているページの内容を読み取ることで 取得します。そのための追加のリクエストは発生しません。HTML ページを自動的に取得する処理 （スクレイピング）は行いません。

4. 要求する権限とその理由

権限 理由
storage 上記 1 の情報をブラウザ内に保存するため。
https://qiita.com/* Qiita 公式 API へのアクセスと、表示中のトレンドページの読み取り・非表示処理のため。 qiita.com 以外のサイトにはアクセスしません。

閲覧履歴を取得する history、タブを操作する tabs、定期実行のための alarms などの権限は要求していません。

5. 第三者への提供

収集した情報を第三者へ提供・販売することはありません。本拡張の単一の目的（Qiita のトレンドから不自然ないいねパターンを検出して隠すこと）と無関係な用途に使用・転送することも ありません。信用調査や融資の判断に使用・転送することもありません。

6. データの削除

  • アクセストークン: 拡張機能の設定画面から削除できます
  • いいねの記録: 7 日を過ぎたものは自動的に削除されます
  • すべて: 拡張機能をアンインストールすると、 chrome.storage.local に保存された情報は削除されます。 chrome.storage.sync の設定値は、Chrome の同期の仕組み上、他の端末での反映に 時間がかかる場合があります

7. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。変更の履歴は ソースコードのリポジトリで確認できます。
