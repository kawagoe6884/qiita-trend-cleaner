Chrome 拡張機能 Qiita Trend Cleaner（以下「本拡張」）／ 最終更新 2026-10-27

本拡張は Qiita 株式会社とは無関係の非公式な拡張機能です。個人が開発・公開しています。

収集したデータを外部のサーバーへ送信することはありません。本拡張の通信先は Qiita の公式 API だけです（ミュートの操作で発生するリクエストは Qiita のページ自身が発行します）。開発者が運営するサーバーはなく、解析ツール・広告・トラッカーも一切組み込んでいません。

1. 保存する情報

本拡張が保存する情報は次のとおりです。どれもお使いのブラウザの中にだけ保存されます。

Qiita アクセストークン

chrome.storage.local

任意の設定です（未設定でも動作します）。Qiita 公式 API の認証にだけ使用し、ほかの送信先には一切送りません。設定画面からいつでも削除できます。

いいねの記録

chrome.storage.local

どのアカウントがどの記事にいつ「いいね」したかの記録です。共起パターンの判定に使用し、7 日を過ぎると自動的に削除されます。

検出結果

chrome.storage.local

検出した候補です。候補の著者の ID と共起したアカウントの ID を含みます。いいねの記録から再計算するたびに置き換わり、元のいいねの記録が削除されると一緒に消えます。

あなたの評価

chrome.storage.local

候補の著者についてあなたが記録した「妥当 / 誤り」の判断です。検出の適合率を計算するための記録なので自動では削除されません（下記 6）。

ミュートの記録

chrome.storage.local

本拡張から Qiita 側のミュートを実行した結果と時刻です（著者ごと）。トレンドに出ていないため見送った場合も記録します。自動では削除されませんが、ミュートを解除した著者がトレンドに戻ってきたと確認できたときは、その著者の記録を削除します。

トレンドに出ていた著者の一覧

chrome.storage.local

最後に読み込んだトレンドページに記事が出ていた著者の ID とその時刻です。ミュート解除の検知と「トレンドに出ていない候補」の案内に使用します。トレンドページを読み込むたびに上書きされ、直近の 1 回分だけを保持します。

著者の巡回記録

chrome.storage.local

アクセストークンを設定した場合だけ保存します。どの著者の過去記事をいつ取得したかの記録で、同じ著者を繰り返し取得しないために使用します。いいねの記録からその著者が消えると一緒に削除されます。

「AI文体かも？」の文体スコア

chrome.storage.local

アクセストークンを設定した場合だけ保存します。トレンド記事の本文を Qiita 公式 API から取得し、ブラウザの中で文体の目安（読点や太字の多さなど）を数えた結果です。記事の本文そのものは保存せず、数え終えたら破棄します。スコアは 7 日を過ぎると自動的に削除されます。

また、本文を取得できなかった記事については記事の ID と時刻だけを記録し、同じ記事を 24 時間は取り直しません（この記録も 24 時間を過ぎると削除されます）。

「AI文体かも？」へのあなたの回答

chrome.storage.local

記事ごとにあなたが押した「そうかも / 違うかも」と、押した時点の点数・該当した文体の項目・時刻です。目安とあなたの感覚の一致率を測るための記録なので自動では削除されません（下記 6）。記事の本文やタイトルは含みません。

動作の状態と表示の設定

chrome.storage.local

ミュート連動の設定・折りたたみの対象・「AI文体かも？」の基準（強調する点数・注釈を付ける字数・薄く表示するか）・最後にスキャンした時刻と件数・API の利用枠が戻る時刻です。個人を識別する情報は含みません。

判定の設定値

chrome.storage.sync

条件の数値（人数・記事数・遡る日数・時間の幅）だけです。Chrome の同期機能を有効にしている場合は、お使いの他の端末にも反映されます。個人を識別する情報は含みません。

2. 他の利用者のアカウント情報について

本拡張は、トレンド記事に「いいね」したアカウントの ID（共起パターンの判定用）と、記事の著者の ID（評価やミュート記録、トレンド表示の有無の案内用）を記録します。

どちらも第三者の情報にあたるため、外部へ送信せずブラウザの中だけで処理します。いいねの記録は 7 日を過ぎると自動的に削除され（保持期間を延ばす設定はありません）、トレンドに出ていた著者の一覧もページを読み込むたびに上書きされます。他の利用者と共有・配布する機能もありません。また、本拡張が表示するのは「いいねの重なり方」と「文体の目安」だけで、不正や規約違反を判定するものではありません。

3. 通信先

本拡張が通信するのは https://qiita.com/api/v2/（Qiita 公式 API）だけです。ミュートは表示中のトレンドページのメニューを操作して行うため、リクエストは Qiita のページ自身が発行します。

トレンドページの記事一覧は、あなたが表示しているページの内容を読み取って取得します。HTML ページを自動的に取得する処理（スクレイピング）は行いません。アクセストークンを設定した場合は、「AI文体かも？」の目安を数えるためにトレンド記事の本文も Qiita 公式 API から取得しますが、ブラウザの中で数えたあと破棄し、どこにも送りません。

4. 要求する権限とその理由

storage

上記 1 の情報をブラウザ内に保存するために使用します。

https://qiita.com/*

Qiita 公式 API へのアクセス、表示中のトレンドページの読み取りと非表示・「AI文体かも？」の表示、およびミュート連動を有効にした場合のミュート操作に使用します。qiita.com 以外のサイトにはアクセスしません。

閲覧履歴を取得する history、タブを操作する tabs、定期実行のための alarms などの権限は要求していません。

5. 第三者への提供

収集した情報を第三者へ提供・販売することはありません。本拡張の単一の目的（Qiita のトレンドを利用者が決めた基準で整理しやすくすること）と無関係な用途や、信用調査・融資の判断に使用・転送することもありません。

6. データの削除

アクセストークンは拡張機能の設定画面からいつでも削除できます。いいねの記録と「AI文体かも？」の文体スコアは 7 日を過ぎると自動的に削除されます。

評価・ミュートの記録・「AI文体かも？」への回答を含め、拡張機能をアンインストールすると chrome.storage.local の情報はすべて削除されます（chrome.storage.sync の設定値は Chrome の同期の仕組みにより他の端末へ反映されるまで時間がかかる場合があります）。

本拡張の記録を消しても Qiita 側のミュートは解除されません。解除は Qiita の設定画面（ミュート設定）から行ってください。

7. 変更

本ポリシーを変更するときはこのページを更新し、最終更新日も改めます。変更の履歴はソースコードのリポジトリで確認できます。
