Chrome 拡張機能 Qiita Trend Cleaner（以下「本拡張」）／ 最終更新 2026-09-28

本拡張はQiita 株式会社とは無関係の非公式な拡張機能です。個人が開発・公開しています。

収集したデータを外部のサーバーへ送信することはありません。本拡張の通信先は Qiita の公式 API だけです（ミュートの操作で発生するリクエストは、Qiita のページ自身が発行します）。開発者が運営するサーバーはありません。解析ツール・広告・トラッカーのたぐいも一切組み込んでいません。

1. 保存する情報

本拡張が保存する情報は次のとおりです。どれもお使いのブラウザの中にだけ保存されます。

Qiita アクセストークン

chrome.storage.local

任意の設定です（未設定でも動作します）。Qiita 公式 API の認証にだけ使用します。ほかの送信先には一切送りません。設定画面からいつでも削除できます。

いいねの記録

chrome.storage.local

どのアカウントがどの記事にいつ「いいね」したかの記録です。共起パターンの判定に使用します。7 日を過ぎると自動的に削除されます。

検出結果

chrome.storage.local

検出した候補です。候補の著者の ID と共起したアカウントの ID を含みます。いいねの記録から作り直すたびに置き換わるので、元のいいねの記録が削除されると一緒に消えます。

あなたの評価

chrome.storage.local

候補の著者についてあなたが記録した「妥当 / 誤り」の判断です。検出の精度を測るための記録なので自動では削除されません（下記 6）。

ミュートの記録

chrome.storage.local

本拡張から Qiita 側のミュートを実行した結果と時刻です（著者ごと）。トレンドに出ていないため見送った場合も記録します。自動では削除されません。ただしミュートを解除した著者がトレンドに戻ってきたと確認できたときは、その著者の記録を削除します。

トレンドに出ていた著者の一覧

chrome.storage.local

最後に読み込んだトレンドページに記事が出ていた著者の ID とその時刻です。ミュート解除の検知と「トレンドに出ていない候補」の案内に使用します。トレンドページを読み込むたびに上書きされます（直近の 1 回分だけを保持します）。

著者の巡回記録

chrome.storage.local

アクセストークンを設定した場合だけ保存します。どの著者の過去記事をいつ取得したかの記録です。同じ著者を繰り返し取得しないために使用します。いいねの記録からその著者が消えると一緒に削除されます。

動作の状態と表示の設定

chrome.storage.local

ミュート連動の設定・折りたたみの対象・最後にスキャンした時刻と件数・API の利用枠が戻る時刻です。個人を識別する情報は含みません。

判定の設定値

chrome.storage.sync

閾値の数値だけです（人数・記事数・遡る日数・時間の幅）。Chrome の同期機能の対象です。同期を有効にしている場合は Google のサーバーを経由してお使いの他の端末にも反映されます。個人を識別する情報は含みません。

2. 他の利用者のアカウント情報について

本拡張は次の 2 種類の Qiita アカウントの ID を記録します。

  • いいねしたアカウント: あなたが表示しているトレンドページの記事に「いいね」したアカウントです。共起パターンの判定に使用します
  • 記事の著者: トレンドに出ていた著者と検出された候補の著者です。評価やミュートの記録に使用します。トレンドに出ているかの案内にも使用します

どちらも第三者の情報にあたるので次のように扱います。

  • 外部へ送信しません。あなたのブラウザの中だけで処理します
  • いいねの記録は7 日を過ぎると自動的に削除されます（保持期間を延ばす設定はありません）
  • 評価とミュートの記録は自動では削除されません（上記 1）
  • トレンドに出ていた著者の一覧はトレンドページを読み込むたびに上書きされます
  • 他の利用者と共有・配布する機能はありません
  • 本拡張が示すのは「不自然ないいねパターン」だけです。不正や規約違反とは断定しません。判断は利用者自身が行います

3. 通信先

本拡張が通信するのは https://qiita.com/api/v2/（Qiita 公式 API）だけです。

ミュートは、表示中のトレンドページのメニューを本拡張が操作して行います。この操作のリクエストは本拡張ではなく、Qiita のページ自身が発行します。

トレンドページの記事一覧はあなたが表示しているページの内容を読み取って取得します。そのための追加のリクエストは発生しません。HTML ページを自動的に取得する処理（スクレイピング）は行いません。

4. 要求する権限とその理由

storage

上記 1 の情報をブラウザ内に保存するため。

https://qiita.com/*

次のために使用します。

  • Qiita 公式 API へのアクセス
  • 表示中のトレンドページの読み取りと非表示の処理
  • ミュート連動を有効にした場合に「妥当」を押した著者をトレンドページ上でミュートすること

qiita.com 以外のサイトにはアクセスしません。

閲覧履歴を取得する history・タブを操作する tabs・定期実行のための alarms などの権限は要求していません。

5. 第三者への提供

収集した情報を第三者へ提供・販売することはありません。本拡張の単一の目的（Qiita のトレンドから不自然ないいねパターンを検出して隠すこと）と無関係な用途に使用・転送することもありません。信用調査や融資の判断に使用・転送することもありません。

6. データの削除

  • アクセストークン: 拡張機能の設定画面から削除できます
  • いいねの記録: 7 日を過ぎると自動的に削除されます
  • 評価とミュートの記録: 個別に削除する機能はありません。下記のアンインストールで削除されます
  • すべて: 拡張機能をアンインストールすると chrome.storage.local の情報はすべて削除されます。chrome.storage.sync の設定値は他の端末に反映されるまで時間がかかる場合があります（Chrome の同期の仕組みによるものです）

本拡張の記録を消しても Qiita 側のミュートは解除されません。解除は Qiita の設定画面（ミュート設定）から行ってください。

7. 変更

本ポリシーを変更するときはこのページを更新します。最終更新日も改めます。変更の履歴はソースコードのリポジトリで確認できます。
