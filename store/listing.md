### 詳細説明

```
※ Qiita 株式会社とは無関係の非公式ツールです。個人が開発・公開しています。

Qiita のトレンドを、あなたが決めた基準で見分けやすくする拡張機能です。

■ 不自然ないいねパターンの検出
同じ顔ぶれのアカウントが、複数の記事に短時間で集中していいねしている――という共起のパターンを、ブラウザの中に蓄積したデータから検出します。
・判定の条件（何アカウント・何記事・何日・何分以内）はあなたが決めます
・検出した著者はポップアップに並び、「妥当 / 誤り」はあなたが判断します
・「妥当」と評価した著者の記事はトレンドから隠せます。Qiita 側のミュートまで行うかは設定で選べます（既定はオフ）
・一括自動ミュートやブロックはしません

■ 「AI文体かも？」（アクセストークンを設定した場合）
トレンド記事の本文から、読点・太字・箇条書きの多さなどの文体の目安を数え、記事の右上に控えめに表示します。
・どこから強調するかはあなたが決めます。強調される記事を薄く表示することもできます（既定はオフ）
・「そうかも / 違うかも」と答えると、目安とあなたの感覚の一致率を確かめられます

■ 断定はしません
この拡張が示すのは「不自然ないいねパターン」と「文体の目安」だけです。不正や規約違反、AI が書いたことを断定しません。誤検知は起こります。判断は必ずあなたが行ってください。

■ データの扱い
・保存先はあなたのブラウザの中（chrome.storage）だけです。外部サーバーへの送信はありません
・通信先は Qiita の公式 API だけです。ミュートは表示中のトレンドページのメニューを操作して行います
・取得した記事の本文は、数えたあと破棄し保存しません。いいねの記録は 7 日で自動的に破棄します
・広告・解析ツール・トラッカーは入っていません

プライバシーポリシー: https://kawagoe6884.github.io/qiita-trend-cleaner/privacy.html
ソースコード: https://github.com/kawagoe6884/qiita-trend-cleaner
不具合の報告・要望: https://github.com/kawagoe6884/qiita-trend-cleaner/issues
```

## プライバシーへの取り組み（Privacy practices タブ）

### 単一目的の説明

```
Qiita のトレンド一覧を、利用者が決めた基準で見分けやすくすること。そのために、不自然ないいねパターンが見られる記事を検出して利用者の評価に応じて隠し、記事の文体から「AI文体かも？」の目安を表示します。
```

### 権限が必要な理由

**storage**

```
判定の条件、検出結果、利用者の評価、いいねの記録（7 日で自動削除）、「AI文体かも？」の点数と回答、任意の Qiita アクセストークンを、利用者のブラウザ内（chrome.storage）に保存するために使います。外部には送信しません。
```

**ホスト権限（https://qiita.com/*）**

```
次の用途に限って使います。(1) Qiita 公式 API（https://qiita.com/api/v2/）から、トレンド記事のいいねと、トークン設定時は記事の本文を取得する。(2) 利用者が表示中のトレンドページを読み取り、評価済みの記事を隠し、「AI文体かも？」の目安を表示する。(3) 利用者が有効にした場合に限り、「妥当」と評価した著者を、表示中のページのメニュー操作でミュートする。qiita.com 以外のサイトにはアクセスしません。
```

### リモートコード

- **いいえ、リモートコードは使用していません**（すべてのスクリプトはパッケージに含まれる）

### データの使用

収集するデータとして申告するもの:

| 種類                                                                                           | 該当 | 内容                                                                   |
| ---------------------------------------------------------------------------------------------- | ---- | ---------------------------------------------------------------------- |
| 認証情報                                                                                       | ✓    | 任意の Qiita アクセストークン（Qiita 公式 API の認証にだけ使う）       |
| ウェブサイトのコンテンツ                                                                       | ✓    | いいねしたアカウントの ID と時刻、トレンド記事の本文（数えたあと破棄） |
| 個人を特定できる情報・健康・財務・個人的な通信・位置情報・ウェブ履歴・ユーザーのアクティビティ | —    | 収集しない                                                             |
