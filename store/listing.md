### 短い説明（132 文字以内）

`manifest.config.ts` の `description` がそのまま使われます。

```
Qiita のトレンドを自分の基準で整理する非公式の拡張機能です。短時間に集中するいいねの検出結果や、AI 文体の目安を表示します。
```

### 詳細説明

```
※ Qiita 株式会社とは無関係の非公式ツールです。個人が開発・公開しています。

Qiita のトレンドを自分の基準で整理する拡張機能です。

■ 不自然ないいねパターンの検出
同じアカウントの集まりが複数の記事へ短時間にいいねしている共起パターンを、ブラウザ内に貯まったデータから見つけます。
判定の条件（何アカウント・何記事・何日・何分以内）はスライダーで自由に変更でき、検出された著者を見て「妥当 / 誤り」をあなた自身が判断します。「妥当」と評価した著者の記事はトレンドから隠せます。また、設定をオンにすれば Qiita 側のミュートも同時に行えます（初期設定はオフ）。一括での自動ミュートやブロックは行いません。

■ 「AI文体かも？」（アクセストークンを設定した場合）
トレンド記事の本文から読点・太字・箇条書きの多さなどの目安を数え、記事の右上に控えめに表示します。
何点から目立たせるかは設定画面で変更でき、対象の記事カードを薄く表示することもできます（初期設定はオフ）。「そうかも / 違うかも」のボタンを押すと、目安とあなたの感覚がどれくらい一致しているかを確認できます。

■ 不正とは決めつけません
この拡張機能が出すのは「いいねの重なり方」と「文体の目安」だけです。不正や規約違反、AI が書いた記事であることを判定するものではありません。誤検知は起きるため、最終的な判断はあなた自身で行ってください。

■ データの扱い
保存先はブラウザの中（chrome.storage）だけで、外部サーバーへの送信はありません。通信先は Qiita の公式 API のみです。ミュート操作は表示中のトレンドページのメニューを操作して行います。また、取得した記事の本文は数えた直後に破棄して保存せず、いいねの記録も 7 日で自動的に削除します。広告・解析ツール・トラッカーは入っていません。

プライバシーポリシー: https://kawagoe6884.github.io/qiita-trend-cleaner/privacy.html
ソースコード: https://github.com/kawagoe6884/qiita-trend-cleaner
不具合の報告・要望: https://github.com/kawagoe6884/qiita-trend-cleaner/issues
```

## プライバシーへの取り組み（Privacy practices タブ）

### 単一目的の説明

```
Qiita のトレンド一覧を、利用者が決めた基準で整理しやすくすること。そのために、短時間に同じメンバーのいいねが重なる記事を検出して利用者の評価に応じて隠し、記事の文体から「AI文体かも？」の目安を表示します。
```

### 権限が必要な理由

#### storage

```
判定の条件、検出結果、利用者の評価、いいねの記録（7 日で自動削除）、「AI文体かも？」の点数と回答、任意の Qiita アクセストークンをブラウザ内（chrome.storage）に保存するために使います。外部には送信しません。
```

#### ホスト権限（https://qiita.com/*）

```
次の 3 つの用途に限って使います。(1) Qiita 公式 API（https://qiita.com/api/v2/）からトレンド記事のいいねと、トークン設定時は記事の本文を取得する。(2) 利用者が表示中のトレンドページを読み取り、評価済みの記事を隠し、「AI文体かも？」の目安を表示する。(3) 利用者が設定を有効にした場合に限り、「妥当」と評価した著者をトレンドページのメニュー操作でミュートする。qiita.com 以外のサイトにはアクセスしません。
```

### リモートコード

パッケージ内のスクリプトのみを使用し、リモートコードは一切使用していません。
